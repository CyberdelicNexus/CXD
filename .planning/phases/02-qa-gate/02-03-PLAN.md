**Add performance smoke test**

Add a test to `e2e/solo-happy-path.spec.ts` (or a new `e2e/performance.spec.ts` if the file is getting large):

```typescript
test('Canvas remains responsive with 10+ elements', async ({ page }) => {
  test.setTimeout(120_000);

  // Open the first canvas (or the board created in the previous test)
  await openFirstCanvas(page);

  // Add 10+ elements by clicking the add button repeatedly
  // Read the ADD_ELEMENT_SELECTOR constant from the top of e2e/solo-happy-path.spec.ts
  // (written by Plan 02-01) and use the same value here.
  // If this test is in solo-happy-path.spec.ts, the constant is already in scope.
  // If in a separate file, copy the concrete selector value.
  for (let i = 0; i < 10; i++) {
    // Click add element button using ADD_ELEMENT_SELECTOR
    await page.waitForTimeout(500); // let each element render
  }

  // Verify 10+ elements exist on canvas
  const elements = page.locator('.card--note-resizable');
  const count = await elements.count();
  console.log(`  Canvas has ${count} elements`);
  expect(count).toBeGreaterThanOrEqual(10);

  // Verify canvas is still interactive:
  // 1. Can we scroll/pan? (move mouse, check no freeze)
  await page.mouse.move(400, 400);
  await page.mouse.move(600, 600);

  // 2. Can we still edit a card?
  const lastCard = elements.last();
  await lastCard.dblclick();
  const input = lastCard.locator('input').first();
  await input.waitFor({ state: 'visible', timeout: 5000 });
  const perfText = `perf-test-${Date.now()}`;
  await input.fill(perfText);
  await page.mouse.click(10, 10);

  // 3. Verify the edit took (page didn't freeze)
  const body = await page.textContent('body');
  expect(body).toContain(perfText);

  console.log('Canvas responsive with 10+ elements');
});
```

If adding elements programmatically is hard (toolbar button not found), an alternative approach:
- Navigate to an existing board that already has 10+ elements, OR
- Use Playwright's `page.evaluate()` to programmatically add elements via the Zustand store:
```typescript
await page.evaluate(() => {
  // Access Zustand store and add elements programmatically
  // This is acceptable for a performance test — we're testing rendering, not creation UI
});
```
