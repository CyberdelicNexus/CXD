  <action>
Elements have `hypercubeTags: HypercubeFaceTag[]` on `CanvasElementBase`. When a new edge is created (connector drawn from element A to element B), the parent (fromNode = A) element's `hypercubeTags` should be propagated to the child (toNode = B).

**Propagation rule:** Union of tags. If parent has `['Reality Planes', 'Core']` and child already has `['Sensory Domains']`, the child should end up with `['Sensory Domains', 'Reality Planes', 'Core']`. No duplicates.

**Implementation locations in cxd-canvas.tsx:**

There are two places where edges are created (search for `syncAddEdge`):

1. **Connector creation via drag** (~line 1186 and ~line 1897): When the user drags from one element's anchor to another element's anchor and releases. After calling `syncAddEdge(newEdge)`, add tag propagation:
   ```typescript
   // Propagate parent tags to child
   const fromEl = canvasElements.find(el => el.id === newEdge.fromNodeId);
   const toEl = canvasElements.find(el => el.id === newEdge.toNodeId);
   if (fromEl?.hypercubeTags?.length) {
     const existingTags = toEl?.hypercubeTags || [];
     const unionTags = [...new Set([...existingTags, ...fromEl.hypercubeTags])];
     if (unionTags.length !== existingTags.length) {
       syncUpdateElement(newEdge.toNodeId, { hypercubeTags: unionTags });
     }
   }
   ```

2. **Programmatic edge creation** (will be used by Plan 03 for cmd+L and context menu connect): These will also need propagation, but they'll be added in Plan 03 when those features are built.

**Do NOT modify `addCanvasEdge` in the store** -- keep propagation in the UI layer where it belongs, since it's a UX-level concern (the store should remain a pure data layer).

Also propagate `taskMetadata.customTags` if they exist on the parent element. Same union logic:
```typescript
if (fromEl?.taskMetadata?.customTags?.length) {
  const existingCustomTags = toEl?.taskMetadata?.customTags || [];
  const unionCustomTags = [...new Set([...existingCustomTags, ...fromEl.taskMetadata.customTags])];
  if (unionCustomTags.length !== existingCustomTags.length) {
    syncUpdateElement(newEdge.toNodeId, {
      taskMetadata: {
        ...toEl?.taskMetadata,
        customTags: unionCustomTags,
      },
    });
  }
}
```
