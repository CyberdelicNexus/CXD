**Auto-organize (CAN-01):**

Create an `autoOrganizeSelected` function (useCallback) that arranges selected elements into an evenly-spaced grid:

1. Get selected elements from `canvasElements` filtered by `selectedElementIds`.
2. If fewer than 2 elements selected, do nothing.
3. Push undo history (`pushCanvasHistory()`).
4. Calculate grid dimensions:
   - `count = selectedElements.length`
   - `cols = Math.ceil(Math.sqrt(count))` (square-ish grid)
   - `rows = Math.ceil(count / cols)`
5. Determine cell size:
   - `maxWidth = Math.max(...selectedElements.map(el => el.width))` (widest element)
   - `maxHeight = Math.max(...selectedElements.map(el => el.height))` (tallest element)
   - `gapX = 40` (horizontal gap between elements)
   - `gapY = 40` (vertical gap between elements)
   - `cellWidth = maxWidth + gapX`
   - `cellHeight = maxHeight + gapY`
6. Determine grid origin: use the centroid of selected elements as the grid center.
   - `centroidX = average of all selected elements' center x`
   - `centroidY = average of all selected elements' center y`
   - `gridStartX = centroidX - (cols * cellWidth) / 2`
   - `gridStartY = centroidY - (rows * cellHeight) / 2`
7. Sort elements by their current position (left-to-right, top-to-bottom -- same spatial sort as connect) to preserve relative arrangement.
8. Assign each element to a grid cell:
   ```typescript
   sortedElements.forEach((el, i) => {
     const col = i % cols;
     const row = Math.floor(i / cols);
     const newX = gridStartX + col * cellWidth + (cellWidth - el.width) / 2; // center in cell
     const newY = gridStartY + row * cellHeight + (cellHeight - el.height) / 2;
     syncUpdateElement(el.id, { x: newX, y: newY });
   });
   ```
9. Also move bend points of edges that connect two selected elements (same pattern as arrow key movement, ~line 2162):
   ```typescript
   canvasEdges.forEach(edge => {
     if (selectedElementIds.has(edge.fromNodeId) && selectedElementIds.has(edge.toNodeId)) {
       // Reset bend to midpoint between new positions
       const fromEl = sortedElements.find(e => e.id === edge.fromNodeId);
       const toEl = sortedElements.find(e => e.id === edge.toNodeId);
       if (fromEl && toEl) {
         // Use new positions (already assigned above)
         // Actually, get from the updated positions we just set
         // Simplest: just remove the bend (set to midpoint of new from/to centers)
         syncUpdateEdge(edge.id, { bend: undefined });
       }
     }
   });
   ```
